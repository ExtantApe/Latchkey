A new name (D197): WelcomeWagon, the neighbors who roll up to greet newcomers. How it works is unchanged. As the owner asked (D196), it keeps no old names.

## Installing over the previous version

With the server stopped:
1. Rename its plugin folder to `plugins/WelcomeWagon`. Invites, sessions and settings are inside.
2. In LuckPerms, move its permissions to the matching `welcomewagon.*` nodes.
3. Use `/welcomewagon` (short form `/ww`) for admin commands. Players still type `/login`.
4. Install the matching Sheriff, BlueMapAuth and Waystation releases, and Leaf Juice's update, at the same time. They find WelcomeWagon by its new name.

Browsers that were signed in sign in once more, because the session cookie has a new name.

## Tested

Unit and HTTP tests pass. The rename was checked with the other plugins on a throwaway server.
