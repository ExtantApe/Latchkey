Two small fixes found by Leaf Juice's checks against 0.6.0.

- Signing a player out everywhere now reports how many **live** sessions it ended, the same number `session list` showed. It still deletes their expired session files too. Before, the two could disagree, for example "signed in on 1 browser" followed by "signed out of 2".
- The README named the old short command. It's `/ww`.

## Installing

Drop the jar in over 0.6.0. Nothing to rename or move.

## Tested

Unit and HTTP tests pass, including a new test for the sign-out count. Not tried on a live server.
